PROJECT VARDAN

Materials Intelligence, Climate Resilience & Fleet Logistics (LCA Stage A1–A4 & B1–B7)

1. Executive Overview

Project Vardan is an embodied carbon intelligence and climate resilience platform engineered for the construction industry. Unlike traditional static calculators that only consider manufacturing emissions (A1–A3), Vardan unifies three integrated Life Cycle Assessment stages under international standards (EN 15978 / ISO 21930 / ICE V5):

  • LCA Module A1–A3 (Product Stage): Baseline embodied carbon extracted from the ICE V5 database across 259 construction materials.
  • LCA Module A4 (Construction Stage — Transport): Fleet logistics emissions calculated dynamically based on curb weight, cargo payload, and transit distance.
  • LCA Module B1–B7 (Use Stage — Operational Degradation): 100-year dynamic Global Warming Potential (GWP) simulated via a Random Forest ML model under regional climate calamity stress.

3. Mathematical Formulation

1. Total Gross Weight: W_total = W_vehicle + W_load
2. Dynamic Load Multiplier: γ = W_total / W_vehicle = 1 + (W_load / W_vehicle)
3. Total Journey Emissions: Emissions_g = Base_Rate × Distance_km × γ
4. Unit Conversion: Emissions_kg = Emissions_g / 1000
5. Normalized Material Factor: E_norm = Emissions_kg / W_load  (kg CO₂e / kg material)
6. Lifecycle Total: Total_Carbon = Base_GWP (A1-A3) + E_norm (A4) + Calamity_Penalty (B1-B7)
